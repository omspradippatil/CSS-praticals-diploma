Exercise 2: How the python script is embedded in html

Answer: Python script is embedded in HTML using PyScript framework:

<!-- Step 1: Include PyScript CSS and JS in <head> -->
<link rel="stylesheet" href="https://pyscript.net/releases/2025.8.1/core.css" />
<script type="module" src="https://pyscript.net/releases/2025.8.1/core.js"></script>

<!-- Step 2: Write Python code in <script type="mpy" terminal> -->
<script type="mpy" terminal>
    print("Welcome")
</script>

Key Points:

  • Include PyScript library in HTML <head>
  • Use <script type="mpy" terminal> tag for Python code
  • "mpy" means MicroPython
  • "terminal" attribute displays output in terminal-like interface
  • Python code runs directly in the browser
